# UIScroller 菜单交互预览

在浏览器中打开 `menu-preview.html`。页面自包含，没有外部字体、图片、脚本或网络请求。复制演示信息可能受浏览器本地文件权限限制。

这是用于评审的 HTML 原型，可切换浅色/深色、待开始/滚动中/更多设置。LINUX DO 仅作为示例阅读背景，实际插件菜单适用于其他受支持的 App，名称自动读取当前 App。

可操作：四档速度、定时预设、自定义时长、开始/停止、关闭/重新打开面板、App 开关和复制演示信息。开始后面板收起，示例正文滚动；点击或滚轮操作正文会停止。

面板外的状态按钮和“打开控制面板”仅用于演示；实际插件仍以双指长按进入。网页不控制设备常亮，不读取真实帖子、账号或设备诊断，不写插件设置。原型设置仅在当前页面会话内保留。

## 原生实现

[UIScrollerMenu.m](../UIScrollerMenu.m) 实现 UIKit 控制面板；[Tweak.xm](../Tweak.xm) 接入真实滚动、定时和常亮状态，设置按 App 保存。

原生版随 1.0.6 RootHide 安装包交付，使用 iOS 17 支持的轻磨砂系统材质。iPad 采用紧凑表单面板；辅助大字号下定时选项纵向排列。HTML 保留设计评审时的独立交互，不代表所有原生细节。

预览已检查桌面和手机的浅色/深色布局；原生版另有 UIKit 交互、深色、大字、键盘和 iPad 检查。验证范围见项目 [README](../README.md#validation)。
